# HR Analytics & Employee Attrition

## Project Overview
This project uses Microsoft Excel and Power Query to analyze employee data, understand workforce trends, and identify factors contributing to employee attrition.

The analysis combines three datasets: General Employee Data, Employee Survey Data, and Manager Survey Data, using `EmployeeID` as the common key.

## Tools Used
- Microsoft Excel
- Power Query
- PivotTables & PivotCharts
- Excel Formulas
- Interactive Dashboards

## Key Activities
- Imported, cleaned, and transformed three CSV datasets.
- Merged datasets using EmployeeID.
- Created calculated fields for HR analysis.
- Analyzed workforce demographics, employee satisfaction, and attrition trends.
- Developed an interactive HR Analytics Dashboard.
- Identified key business insights and provided recommendations to HR management.

## Key Performance Indicators (KPIs)
- Total Employees
- Employee Attrition Rate
- Average Monthly Income
- Average Job Satisfaction
- Average Performance Rating

## Project Deliverables
- Cleaned and merged dataset.
- HR analysis and PivotTables.
- Interactive Excel dashboard.
- Business insights and recommendations.

## Dataset
IBM HR Analytics – Employee Attrition dataset (Kaggle).
